# Aplicações frontend

Este diretório organiza aplicações por plataforma. Não coloque arquivos de uma aplicação diretamente aqui: crie uma pasta própria dentro da plataforma adequada.

- [Web](web/README.md): aplicações executadas no navegador.
- [Smartphone](smartphone/README.md): aplicações móveis para celulares.
- [Desktop](desktop/README.md): aplicações instaláveis para computadores.
