# Aplicações para smartphone

Este diretório é reservado para aplicações destinadas a smartphones. Crie uma pasta independente por produto, incluindo seu código, dependências, instruções de execução e testes.

Não coloque uma aplicação diretamente em `apps/frontend/smartphone/`; use um nome descritivo, por exemplo `apps/frontend/smartphone/meu-aplicativo/`.

## Aplicação disponível

- [`diagnosticopinpad`](diagnosticopinpad/) — laboratório Android da Change 068;
  depende do AAR gerado pelo módulo Go e mantém o protocolo PBRG binário.
