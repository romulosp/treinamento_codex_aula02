# Lunara — template-ecommercer-001

Template demonstrativo de e-commerce de moda feminina premium. A Fase 1 entrega somente design system, shell e cabeçalho; não há catálogo, persistência, checkout ou integração externa nesta etapa.

## Executar

```powershell
npm install
npm run dev
```

## Verificar

```powershell
npm run test
npm run lint
npm run build
```
