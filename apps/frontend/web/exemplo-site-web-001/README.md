# Terra & Torra — exemplo-site-web-001

Vitrine demonstrativa de cafés especiais, criada com React 19, TypeScript e Vite. Usa somente dados fictícios locais; não integra pagamento, autenticação, APIs ou coleta de dados pessoais.

## Executar

```powershell
npm install
npm run dev
```

## Verificar

```powershell
npm run test
npm run lint
npm run build
npm audit --audit-level=moderate
```
