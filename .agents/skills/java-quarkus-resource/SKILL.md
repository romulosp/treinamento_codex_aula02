# Recursos REST Quarkus

1. Leia a SPEC e as convenções REST antes de criar código.
2. Use DTOs para requests e responses; nunca retorne entidades de persistência.
3. Mantenha regras de negócio na camada de aplicação.
4. Documente o contrato quando ele for público e cubra cenários com testes.
